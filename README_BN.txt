দোকান AI সহকারী — প্রথম পরীক্ষামূলক সংস্করণ

এই ফোল্ডারের ফাইলগুলো একটি installable PWA তৈরি করে।
Android-এ ইনস্টল করতে HTTPS ওয়েব হোস্টিং প্রয়োজন (যেমন GitHub Pages)।
শুধু index.html ফোনে খুললে সার্চ ও CSV import পরীক্ষা করা যায়, তবে ইনস্টল/সার্ভিস-ওয়ার্কার অফলাইন ক্যাশের জন্য HTTPS hosting দরকার।

ব্যবহার:
1. প্রথমে index.html খুলুন বা HTTPS-এ প্রকাশিত অ্যাপ খুলুন।
2. পণ্যের নাম লিখে সার্চ করুন।
3. CSV ফাইল বাছাই করে ফোনে ডেটা সংরক্ষণ করুন।
4. Google Sheets-এর CSV URL যোগ করে Sync ব্যবহার করা যাবে; শিট প্রকাশ করলে লিংকধারীরা তথ্য দেখতে পারে।
5. এই সংস্করণে দ্বিমুখী সিঙ্ক, AI chat এবং voice নেই। এগুলো পরবর্তী ধাপে যোগ হবে।
